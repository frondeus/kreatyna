MAC-05 — Create an ingredient from the toolbar

Target state after MAC-05. ＋ replaces the detail pane with the Rust form widget (E-04). Swift renders the form view and sends events; Rust validates, saves, and decides what the pane shows next.

Each section shows the chosen variant. The options that were not chosen are behind the “Alternatives” toggles.

1 · Press ＋: the form and a draft row MAC-05/Q2: C

Start: Garlic is open. Action: press ＋ (or ⌘N). The pane becomes the empty form, and the cursor is in Name. A highlighted draft row appears at the top of the list, as in macOS Contacts and Notes. It shows the typed name, or “New Ingredient” while the name is empty. The search never hides it. Save puts the real row at its sorted place; Cancel removes the draft row and brings back Garlic. A click on the draft row does nothing. ＋ is disabled while a form is open. Esc is Cancel; ⌘S is Save.

3 · Reference units: remove and reorder MAC-05/Q4: − button + drag

Each unit has a remove button (−) and a drag handle (≡). You drag a unit by its handle to reorder it. If drag does not work inside a grouped form on macOS, the plan falls back to the first alternative below, and the delivery report says so.

8 · A row click on a dirty form MAC-05/Q1: E-10 now

Action: type “Pap”, then click Tomato. macOS shows the question as a sheet from the top of the window. Discard Changes opens Tomato. Keep Editing closes the sheet; the form keeps “Pap”. A clean form opens Tomato at once. Cancel on a dirty form asks the same question and then returns to the previous pane. MAC-06 reuses the rule for the edit form.
