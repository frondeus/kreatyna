REC-17 · How you set a step's duration

Design round for the inspector's Duration field. Each variant below works: type in it, click it, or use the example buttons to fill every variant at once. Under each one you see what Rust would store and what the canvas node would show. The step is "Bake sauce" from the Pasta recipe.

1 · Duration variants MVP

Decided: E. A to D stay for the record. Fill every variant with a real step from a recipe. Each example needs a different unit. That is the point of the comparison: a sear takes seconds and a marinade takes days.

Decided

  • D-21 A duration is one value. Ranges ("8 to 10 min") are parked as F-06.
  • Q-R5 A new step has no duration until you set one. REC-22 later makes it required on Save.
  • REC-17/Q2 The read view shows the title, the duration, "waiting", and the instructions.
  • REC-17/Q1 The inspector uses variant E: presets, a minutes field, and More… for the unit fields.
  • REC-17/Q3 Durations have seconds. Rust stores one whole number of seconds.
  • REC-17/Q4 Durations go up to 365 days, for long recipes such as a sourdough starter.

2 · How Rust writes a duration MVP

Every variant shows the same text on the node, in the read view, and later in REC-21's total time. Rust writes the largest units first, and leaves out the units that are zero.
